OriVR 1.2.2: Ori and the Blind Forest: Definitive Edition in VR (free mod, OpenXR)

Ori as a floating 3D diorama in front of you. This is true native stereo: both eyes are drawn from the same game tick, with no alternate-eye rendering and no warping. The game's real depth layers stay real, so the background sits behind the stage and the foreground comes out toward you. Play it seated with a gamepad.

What it does
- Native stereo through OpenXR, using the game's own 3D layers
- The game runs at your headset's refresh rate, at normal game speed
- Resolution set from your headset's pixel density and the stage size
- In-headset settings menu in the game's own font. Click both sticks to open it
- Sliders for stage distance, stage size, depth, pop-out, sharpening and resolution
- Installs with one bat file, and uninstalls the same way. No game files are changed

What you need
- The Steam version of Ori and the Blind Forest: Definitive Edition
- A PC VR headset with a 32-bit OpenXR runtime: SteamVR 2.17 or newer set as your OpenXR runtime, or Virtual Desktop's VDXR
- A gamepad

Please read
- Tested in real headsets on two setups: Pimax Dream Air through SteamVR, and Meta Quest 3 through Virtual Desktop's VDXR. Other headsets and graphics cards should work but have not been tried. Reports are welcome.
- There is no DLSS. The game is 32-bit, and DLSS needs a 64-bit game.
- The mod is not signed, so Windows may warn you, and Smart App Control can block it. The README covers this.

Install
Unzip it, double click "Install OriVR.bat", and type 1. Start SteamVR or connect Virtual Desktop, then start Ori from Steam.
